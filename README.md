# Enterprise BI Suite – Business Intelligence & Sales Analytics

## Project Overview

Enterprise BI Suite is an end-to-end Business Intelligence project developed using the AdventureWorksDW2025 dataset. The project focuses on analysing internet sales performance and presenting business insights through SQL, Power Query, DAX and Power BI.

## Business Objectives

- Analyse overall sales and profitability.
- Monitor sales performance across years and months.
- Compare product category performance.
- Evaluate sales across different territories.
- Develop an interactive dashboard for business reporting.

## Dataset

**Database:** AdventureWorksDW2025

**Main Tables:**

- FactInternetSales
- DimDate
- DimCustomer
- DimProduct
- DimProductCategory
- DimProductSubcategory
- DimGeography
- DimSalesTerritory

## Tools and Technologies

- **SQL Server 2025** – Data querying and analysis
- **Power Query** – Data transformation and preparation
- **Power BI** – Dashboard development and visualization
- **DAX** – KPI calculations and measures

## Project Workflow

1. Explore and analyse the database using SQL.
2. Transform and prepare data using Power Query.
3. Configure data relationships in Power BI.
4. Create DAX measures for business KPIs.
5. Develop an interactive Power BI dashboard.
6. Validate dashboard metrics against SQL results.

## Key Performance Indicators

- Total Revenue
- Total Orders
- Total Profit
- Profit Margin
- Total Cost
- Average Order Value

## Dashboard Visualizations

- Monthly Sales Trend
- Sales by Year
- Sales by Product Category
- Sales by Territory

## Key Business Findings

- Revenue and profit provide an overview of overall business performance.
- Monthly sales trends help identify changes in sales over time.
- Product category comparisons highlight revenue contributions.
- Territory analysis shows differences in regional sales performance.
